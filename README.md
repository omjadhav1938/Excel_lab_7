# Excel Lab 7 – Region-wise Sales Insights

## 📌 Overview

This lab focuses on analyzing the **DeMart sales dataset** using Microsoft Excel to generate region-wise sales insights.

## 🎯 Tasks Completed

* Calculated **Total Orders by Region** using `COUNTIF`
